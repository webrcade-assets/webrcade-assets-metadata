Syphon Filter: Combat Ops is an online only game for the PSP, using the same multiplayer engine as Syphon Filter: Dark Mirror and Logan's Shadow. You can use the mission modifier to create your own maps, and populate them the way you want. Place weapons, spawn points, ladders, barrels, etc. Existing maps can be modified as well. The names of the factions can be modified and the creator can determine what factions to include in the mission. Combat Ops is exclusive to the Playstation Store for PC, and is the first PSN supported game for the PSP. New missions and maps can be shared through Wi-Fi Ad-hoc.
