2048 is a puzzle game played on a 4x4 grid that holds tiles with values on them. The tiles slide in four directions controlled by the player. Each time the tiles slide, tiles of the same value that collide with each other are merged to create a new tile with the combined value. The objective is to create a tile with the value 2048. The Apple II version was developed and published by Ikigai Software and released in November of 2020.
