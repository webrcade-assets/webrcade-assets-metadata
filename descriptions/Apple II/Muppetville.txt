Muppetville is an educational software program for the Apple IIe computer released in 1986 by Sunburst Communications. It was intended for preschoolers, and was compatible with the Muppet Learning Keys keyboard. It was designed by Christopher Cerf, Mike Fish, Joni Jablonsky, and Anders McCarthy. The game featured Kermit the Frog, Miss Piggy, Fozzie Bear, Statler and Waldorf, Animal, Gonzo, Camilla the Chicken, Beaker, Dr. Bunsen Honeydew, and Sam the Eagle. It contains six basic education games: -  Apartments: matching game for sounds -  Factory: basic addition questions up to 10. -  Hotel: matching card game for shapes -  Movie House: learn a word that begins with each letter of the alphabet -  School: matching game involving numbers -  Zoo: choosing which of shapes is different from the others
