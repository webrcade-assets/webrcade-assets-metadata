Cubik is a three dimensional Tic-tac-toe game similar to the board game Qubic. It can be played by two players or one player against the computer. The game is played on a cube that contains four planes that each are four rows deep and four rows wide. The aim is to get four tokens in a row. The row can be vertical, diagonal or horizontal through the cube or on any of the planes. The game is played with the keyboard and for each move the player enters the number of the plane, the row and the column.
