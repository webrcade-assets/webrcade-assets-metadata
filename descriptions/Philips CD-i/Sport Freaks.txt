Sport Freaks is a sports quiz game based on a Dutch television game show of the same name. The game includes all the questions that were written for the show but were never used. All the questions relate to a selection of 45 sports in 50 countries since the year 1900. The number of questions in the game (1250) equals 60 game show episodes. Using a sort of slot machine each turn a sport, year and country is chosen which you receive a question about. The emphasis lies on Dutch sports history.
